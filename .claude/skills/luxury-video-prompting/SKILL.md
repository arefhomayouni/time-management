# Luxury Video Prompting Skill

This skill helps create high-end AI video prompts for landing pages.

## Instructions
When this skill is invoked, follow these steps to generate prompts:

1. **Image Prompt**: Describe the complete visual space. Include:
   - Background, visual elements, and branding.
   - Lighting (e.g., cinematic, soft, volumetric).
   - Color palette (e.g., luxury gold, deep matte black, minimal white).
   - Frame composition (e.g., wide shot, macro, centered).

2. **Motion Prompt**: Describe the movement between frames. Include:
   - What enters or leaves the frame.
   - Movement speed and direction.
   - Transition type (e.g., slow glide, fast zoom, fade).

3. **Technical Settings**: Specify for the generator:
   - Duration, Start Frame, and End Frame.
   - Motion Strength (adjust based on scene intensity).
